化学学习系统 · Windows 本地部署器 使用说明
================================================================

一、这是什么
  一个 exe 文件，双击就能把整套化学学习系统部署到这台 Windows 电脑上：
  前端页面、后端接口、453 道题库全部内置，不需要安装 Python、数据库或
  任何服务器软件。部署完成后浏览器会自动打开，同一个局域网里的手机、
  平板、其它电脑也能访问。

二、最快的用法
  1. 把 ChemLearnWindows.exe 放到任意目录（桌面也行）
  2. 双击运行，等 3~10 秒（首次会先解压运行环境）
  3. 窗口显示“已启动 · 运行中”，浏览器自动打开
     http://127.0.0.1:8000/chem/app/
  4. 用 admin / admin123 登录，登录后请到“个人中心”修改密码

  关闭窗口 = 停止服务；下次双击重新启动，数据都还在。

三、给局域网里的其它设备用
  窗口里“局域网访问”一栏会显示类似：
      http://192.168.1.5:8000/chem/app/
  把这个地址发给学生/同事即可（必须在同一个 Wi-Fi 或交换机下）。

  如果对方打不开，通常是本机防火墙拦了端口：
    控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
    → 勾选本程序（专用网络）
  也可以在窗口左下角把端口改成 80 之类再启动。

四、数据存在哪
  C:\Users\<你的用户名>\AppData\Local\ChemLearnWindows
  ├─ backend\chemlearn.db   题库、账号、练习记录（都在这个文件里）
  ├─ backend\uploads\       上传的图片和试卷
  └─ deployer.log           运行日志（排障时看这个）

  备份：把整个 ChemLearnWindows 文件夹复制走即可。
  升级 exe：直接替换新 exe 双击运行，会自动更新程序、保留数据库。
  彻底卸载：先关闭程序，再删除上面这个文件夹。

五、按钮说明
  打开系统     在浏览器里打开本机地址
  数据目录     打开数据文件夹（备份用）
  重新部署…    清空所有数据，把题库恢复成内置的 453 题（不可撤销，会二次确认）
  停止服务     停止后台服务（不退出窗口），之后可点“重试启动”
  退出         停止服务并关闭窗口

六、命令行参数（进阶）
  ChemLearnWindows.exe                  默认 8000 端口
  ChemLearnWindows.exe --port 8090      换端口（被占用会自动往后找）
  ChemLearnWindows.exe --no-browser     启动后不自动打开浏览器
  ChemLearnWindows.exe --reset          启动时清空数据重新部署
  ChemLearnWindows.exe --version        弹窗显示版本号
  ChemLearnWindows.exe --console        仅源码运行时有效：exe 是无控制台窗口程序，
                                        该参数会被忽略并回到图形界面

七、常见问题
  Q: 双击后窗口一闪就没了？
  A: 说明启动时出错。看同目录 deployer.log，或把
     C:\Users\<用户名>\AppData\Local\ChemLearnWindows\deployer.log 发出来。

  Q: 杀毒软件/Windows 提示“未知发布者”？
  A: exe 没有代码签名，Windows SmartScreen 会提示。点“更多信息 →
     仍要运行”。程序本身不联网、不改系统设置，只在自己目录里写文件。

  Q: 页面打不开或空白？
  A: 等状态变成“已启动 · 运行中”再刷新；或按 Ctrl + Shift + R 强制刷新。

  Q: 端口 8000 被占用？
  A: 程序会自动往后找空闲端口，窗口里显示的地址就是实际地址；
     也可以手动改左下角端口（会重启服务）。

  Q: 想让学生在外网访问？
  A: 这是本机部署版，只适合局域网。需要公网请用仓库里的 Linux 服务器
     部署器（deployer/linux/），配合 nginx + HTTPS。

  Q: AI 问答/套卷生成能用吗？
  A: 需要自己准备大模型 API Key，登录管理员账号后在“系统设置”里填写，
     部署包不包含 Key。

八、化学连连看（v2.1 新增）
  系统内置「化学连连看」：把物质与俗名、官能团与性质、方程式与现象、
  名称与化学式两两配对，全部配对完成后按用时、错误次数和连击计分。
  · 学生：左侧菜单「化学连连看」→ 选关卡 → 依次点两张卡配对
  · 老师 / 管理员：左侧「连连看管理」→ 新建关卡（手动录入或批量粘贴），
    或「批量导入」上传 Excel / CSV / TXT；导入模板在管理页右上角下载
  · 部署包已附带 4 套示例关卡，装好即可直接玩
  · 学生成绩会记录，老师在每套关卡的「记录」里能看到学生得分与正确率

九、和 Linux 部署器的区别
  Windows 版：装在这一台电脑上，关机就停，适合个人、教研室、小范围使用。
  Linux 版：装到 Ubuntu 服务器，开机自启、长期在线，适合全校/全组使用。

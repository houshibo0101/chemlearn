# 套卷练习

把一份真实试卷变成可在线作答、自动判分的页面。这是本项目的核心功能。

---

## 整体流程

```
上传 PDF / TXT
      ↓
渲染页面图（150dpi）→ 存下来，OCR 和配图共用
      ↓
有文字层？──是→ 直接提取文字
      └──否→ 逐页视觉识别（多模态模型）
      ↓
按页拼接文本，插入【第N页】标记
      ↓
AI 转结构化 JSON（题干、选项、答案、页码、是否需要看图）
      ↓
规则纠偏 + 去重 + 分值对齐
      ↓
写入 questions 表 → 模板渲染做题页
      ↓
学生限时作答 → 交卷 → 服务端判分 → 错题进错题本
```

---

## 上传

进入「套卷练习」→「上传试卷」，填写：

| 字段 | 说明 |
|---|---|
| 文件 | PDF / TXT / MD，PDF 单份不超过 40 页 |
| 卷名 | 例如「2024年广东省普通高中学业水平选择性考试 化学」 |
| 省份 / 年份 / 类型 | 用于筛选 |
| 时长 / 总分 | 决定倒计时和成绩单分母 |

**权限**：管理员上传直接通过并开始生成；学生上传需要审核，通过后才生成。

## 生成过程

一份 8 页的扫描版 PDF 大约需要 **4 分钟**：

| 进度 | 阶段 | 实测耗时 |
|---|---|---|
| 6–12% | 渲染 PDF 页面 | 秒级 |
| 15–45% | 识别扫描页 N/M | 约 47 秒（8 页，并发 3） |
| 50% | AI 结构化 | — |
| 50–86% | 解析第 N/M 段 | 约 150 秒 |
| 88% | 整理题目（去重合并） | 秒级 |
| 94% | 写入题库 | 秒级 |
| 100% | 生成完成 | 总计约 244 秒 |

页面会显示进度条和带时间戳的实时日志。AI 解析阶段较慢，每 12 秒刷新一次「已等 N 秒」，避免看着像卡死。

---

## 扫描版 PDF 怎么处理

没有文字层的 PDF（手机拍的、扫描的）会走视觉识别：

- 每页渲染成 150dpi 的 PNG
- 交给多模态模型逐页识别
- 化学式下标识别准确（实测 `CaSO₄`、`Na₂CO₃`、`H₃PO₄` 都对）

> 局限：扫描件每页就是一整张图，拿不到"这道题的图在哪一段"的坐标，
> 所以带图的题只能**附整页原图**（可点开看大图）。文字型 PDF 没这个问题。

## 判分

### 服务端判分，分两层

**选择题**：归一化后严格比对，不走 AI。

**主观题**：AI 阅卷，一次请求判完所有非选择题。判分原则写死在 prompt 里：

- 意思对就算对，不因表述、顺序、繁简判错
- 化学式 / 离子符号等价写法算对（`H⁺` 与 `H+`、`SO₄²⁻` 与 `SO4^2-`）
- 数值题允许有效数字和单位写法差异，但数值必须对、单位错判错
- 方程式未配平、漏条件（加热 / 催化剂 / ↑↓）判错
- 分小问的题，任何一个小问错就判错

判完会返回一句理由，显示在成绩单上。

### 标准答案可校对

AI 提取的答案可能有误，所以：

**管理员 → 套卷卡片 →「校对答案」** → 表格列出每题的题干、标准答案、解析，直接改，失焦自动保存。

改完立即生效：判分用它，做题页也会重新渲染。

这一步是准确性的根本——老师的判断比任何算法都可靠。

### 没有标准答案的题

不参与判分，也不计入满分（否则学生做对也扣分），成绩单会注明「N 题参考答案缺失」。

## 反作弊

| 措施 | 说明 |
|---|---|
| **服务端计时** | 开始时间存在服务端，刷新页面、关掉重进都拿不回时间 |
| **绝对时间倒计时** | 不用递减计数器，避免浏览器把后台标签定时器节流导致"切屏停表" |
| 切屏检测 | 第 1 次提示，第 3 次警告，第 5 次自动交卷；顶部显示「离开 N 次」 |
| 禁止复制粘贴 | 答题期间拦截 copy / cut / paste / 右键 |
| 超时标记 | 交卷时按真实耗时判断，超时会在成绩单注明 |

> 这些只能提高作弊成本。要真正防住「另一台设备搜答案」，得靠摄像头监考或题目随机化。

## 已知限制

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 生成的题数少于卷面 | AI 漏题，长材料容易整段跳过 | 重新生成；或提示里已给出「分值合计低于设定总分」的警告 |
| 单题分值偏高 | 卷面没标分值，AI 按总分平均 | 分值上限已设为总分的 20%（写作 35%），超出会截断 |
| 阅读/完形题型标错 | 小模型判断不稳 | 后端有规则纠偏：有材料且含 `__` 空格 → 完形，无空格 → 阅读 |
| 扫描件配图是整页 | 拿不到题目区域坐标 | 点击放大看原图 |
| 总分为 0 或缺失 | 未填总分 | 上传时必填 |

## 相关接口

```
POST   /api/v1/papers/upload                上传（multipart）
GET    /api/v1/papers                       列表（分页、筛选）
POST   /api/v1/papers/{id}/regenerate        重新生成
POST   /api/v1/papers/{id}/review            审核（管理员）
GET    /api/v1/papers/{id}/page              做题页（HTML）
GET    /api/v1/papers/{id}/pageimg/{n}       原卷页面图
POST   /api/v1/papers/{id}/start             开始答题（返回剩余秒数）
POST   /api/v1/papers/{id}/submit            交卷判分
GET    /api/v1/papers/{id}/questions         题目明细（校对用）
PATCH  /api/v1/papers/{id}/questions/{no}    修改单题答案/解析
```

# 化学学习系统 · ChemLearn

面向高中化学的在线学习平台：题库刷题、错题本、AI 问答、套卷限时练习、班级与作业管理、学习报告。

前后端分离，单机可跑，数据存在 SQLite，不需要额外装数据库。

## 能做什么

### 学生学习
- **刷题**：按学段、难度、题型、知识点筛选，顺序练习或随机组卷，答完即时判分
- **套卷限时练习**：整份高考卷限时作答，交卷自动判分，错题进错题本
- **错题本**：自动收录，可重做、导出 PDF / Excel；支持 AI 讲解和自动出变式题
- **AI 问答**：针对题目提问，支持多轮对话
- **学习报告**：正确率趋势、知识点掌握度

### 老师教学
- **班级管理**：建班、邀请学生、查看班级练习情况
- **作业 / 考试**：布置、批阅、统计得分与正确率
- **学生错题**：按学生查看错题分布
- **题目上传**：Excel / PDF 批量导入，或单题录入
- **套卷**：上传试卷，AI 自动生成做题页；可校对标准答案

### 管理员
- 账号管理（学生 / 教师 / 管理员三种角色，批量导入、重置密码）
- 题库管理、API 密钥、全局数据看板

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vite + Element Plus + Pinia |
| 后端 | FastAPI + SQLAlchemy 2.x（async） |
| 数据库 | SQLite（单文件，备份就是拷文件） |
| 文档解析 | PyPDF2（文字层）、PyMuPDF（扫描件渲染） |
| AI | 火山引擎方舟（OpenAI 兼容协议），豆包 + DeepSeek |

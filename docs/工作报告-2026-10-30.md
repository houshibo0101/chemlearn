## 二、新功能

### 1. 套卷限时练习（本期主线）

完整实现了需求里的五个环节：

| 环节 | 实现 |
|---|---|
| 各省高考卷 | 列表按省份、年份、考试类型筛选展示 |
| 管理员上传 | 上传即通过，后台立即开始生成 |
| 学生上传需审核 | 默认 `pending`，管理员通过/驳回（填原因），通过后自动生成 |
| AI 生成做题页 | PDF→文本→AI→题目入库→模板渲染 HTML |
| 下次直接跳转 | 列表点「开始做题」打开那一页，按卷独立保存，可反复进入 |
| 错题同步 | 交卷时判分，错题写 `wrong_questions`，每题写一条练习记录 |

做题页包含：倒计时、题号导航、单选/多选/填空、交卷后逐题标对错、正确答案与解析、顶部成绩卡。

### 2. AI 接入（火山引擎方舟）

- 问答用 `doubao-seed-2-0-mini-260428`，解析类（错题讲解）用 `deepseek-v4-flash-ga-260731`
- 配置项：`AI_API_KEY` / `AI_API_BASE` / `AI_MODEL` / `AI_EXPLAIN_MODEL`
- 部署器界面可直接填写，装完即用，不用再登录服务器改 `.env`

### 3. 扫描版 PDF 识别 + 配图

- 没有文字层的 PDF 逐页渲染成图，交给多模态模型识别（8 页约 47 秒）
- 化学式下标识别准确：`CaSO₄`、`Na₂CO₃`、`H₃PO₄`
- 带图的题自动附上原卷页面图，可点击看大图

### 4. 判分体系（三层）

1. **标准答案可校对**：管理员在套卷卡片点「校对答案」，逐题改答案/解析，判分和做题页同步生效
2. **选择题精确比对**：归一化后严格相等，不走 AI
3. **主观题 AI 阅卷**：一次请求判完所有非选择题，返回对错 + 理由；AI 不可用时回退规则匹配

实测：换个说法但意思正确 → 判对；只答一半 → 判错；方程式漏配平 → 判错。

### 5. 返回入口 + 反作弊

- 做题页左上角「←」返回列表
- **服务端计时**：刷新/切后台都不重置、不停表（原来用递减计数器，浏览器节流后台定时器等于送时间）
- 切屏检测：提示 → 警告 → 第 5 次自动交卷，顶部显示「离开 N 次」
- 禁止复制题目/粘贴答案/右键
- 超时提交会标记 `overtime`，成绩单注明

### 6. 生成进度可视化

生成一份卷要 3-4 分钟，现在能看到：

```
识别扫描页 7/8 ———————————— 41%
  00:11:25  第 5/8 页识别完成
  00:11:29  第 6/8 页识别完成
```

进度分 9 个阶段埋点，长耗时阶段有心跳（「AI 正在解析题目（已等 156 秒）」）。

### 7. 题目收藏

前端页面早就在，后端一直没实现（打开就 404）。补上 `favorites` 表和 4 个接口，刷题页的星标现在是真收藏。

### 8. AI 讲解 / 变式题改后台任务

原来要同步等几十秒。现在提交任务立即返回，后台执行，完成后写通知，用户可以去干别的；中途关页面也不丢，重新打开会接回来继续轮询。

### 9. 错误提示对应化

登录密码错误不再提示「登录已过期」。401 按接口分流，403/404/422/429/5xx 各自对应文案，优先用后端返回的具体原因。

## 三、修掉的问题

| 问题 | 现象 | 原因 |
|---|---|---|
| 收藏 404 | 打开「我的收藏」报 not found | 前端在调 `/favorites`，后端从未实现 |
| 倒计时停表 | 切到别的标签页，倒计时几乎不走 | 递减计数器 + 浏览器对后台标签节流定时器 |
| 总分对不上 | 题目分值和 98 / 119 / 106，满分写 100 | AI 给的分值从不等于目标总分，学生全对也拿不到满分 |
| 题号重复 | 49 题（实际 19 题） | 试卷自带答案页，同一批题被解析两遍 |
| JSON 解析失败 | 整卷生成失败 | 卷面 `5％`、`\(1\)` 被 AI 原样输出成非法转义 |
| 分值不落库 | 算出来 100，数据库还是 98 | SQLAlchemy JSON 列不追踪内部元素改动，需 `flag_modified` |
| 任务卡死 | 后台任务永远 running | `except` 块里用了未 import 的 `datetime`，异常处理自身抛错 |
| 密码错误提示错 | 显示「登录已过期」 | 响应拦截器把所有 401 当 token 失效 |
